# Custom Domain — ZenTec Gateway

Production domain:

```text
https://zentec-gateway.zenqor.com.my
```

## Vercel

1. Deploy/import the `zenqor-gateway` project.
2. Open Project → Settings → Domains.
3. Add `zentec-gateway.zenqor.com.my` and assign it to Production.
4. Vercel will display the exact DNS record required. For a third-party DNS provider, a subdomain normally uses a CNAME. Use the project-specific target Vercel displays instead of guessing it.
5. At the DNS provider for `zenqor.com.my`, create the record for host `zentec-gateway`. Remove any conflicting A/AAAA/CNAME record at that same host.
6. Return to Vercel and wait for the domain to show Valid Configuration. Vercel handles HTTPS/TLS after DNS verification.

## Vercel Environment Variable

Add to Production (and Preview only if you intentionally want preview Bills to return to production):

```env
APP_URL=https://zentec-gateway.zenqor.com.my
```

## Billplz URLs generated by this project

```text
callback_url=https://zentec-gateway.zenqor.com.my/api/billplz/callback
redirect_url=https://zentec-gateway.zenqor.com.my/payment/result
```

You do not need to hard-code these in the Billplz dashboard; they are sent when this project creates each Bill.
